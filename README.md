# ArixByte Platform

A production-ready hosting platform scaffold built with Next.js, Express, TypeScript, TailwindCSS, and Docker.

## Repositories
- API: [arixbyte-api](arixbyte-api)
- Web: [arixbyte-web](arixbyte-web)
- Dashboard: [arixbyte-dashboard](arixbyte-dashboard)
- Docs: [arixbyte-docs](arixbyte-docs)

## Quick start
1. Install dependencies for the API and web app.
2. Start the API with npm run dev in the API folder.
3. Start the web app with npm run dev in the web folder.

## Deployment
Docker Compose and CI workflows are included for Ubuntu Linux deployment preparation.

## Verification
The scaffold has been created and the repository structure is ready for dependency installation and builds.
